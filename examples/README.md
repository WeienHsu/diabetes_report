# 示範資料與格式規格

```bash
uv run agp-report --glucose examples/glucose.csv --food examples/food.csv \
                  --days 14 --out out/demo.html
```

線上版直接把這兩個檔案丟上去也可以。

**這裡的資料完全是合成的**——不是把真實紀錄去識別化，而是用固定亂數種子從頭造出來的。
產生方式見 `generate.py`，可重複執行得到相同結果。

---

## 為什麼有這份檔案

本專案原本只吃雅培 FreeStyle Libre 的匯出格式。但只要**你的裝置能把資料轉成
下列欄位**，這個專案就能用——這兩個檔案就是那份規格的可執行版本。

不確定自己轉得對不對時，拿這裡的檔案跟你的並排比對最快。

---

## glucose.csv — 血糖與胰島素

第 1 列是抬頭，**第 2 列才是欄位名，第 3 列起為資料**。解析時第 1 列直接跳過。

```
葡萄糖資料,產生於,2026-03-16 00:00 UTC,產生者,示範使用者
裝置,序號,裝置時間戳記,記錄類型,歷史葡萄糖 mg/dL,...
FreeStyle LibreLink,DEMO-0000,2026-03-02 00:00,0,117,,,,...
```

**必要欄位**（欄位以名稱比對，順序不拘，多餘的欄位會被忽略）：

| 欄位名 | 說明 |
|---|---|
| `裝置時間戳記` | `YYYY-MM-DD HH:MM`，24 小時制 |
| `記錄類型` | 決定這一列的意義，見下表 |
| `歷史葡萄糖 mg/dL` | 記錄類型 `0` 時填 |
| `掃描葡萄糖 mg/dL` | 記錄類型 `1` 時填 |
| `速效胰島素（單位）` | 記錄類型 `4` 時填 |

**記錄類型**：

| 值 | 意義 | 用途 |
|---|---|---|
| `0` | 歷史葡萄糖，感測器每 15 分鐘自動記錄 | **所有指標唯一的來源** |
| `1` | 掃描葡萄糖，使用者主動刷卡的即時值 | 只畫在每日詳圖上，不參與任何統計 |
| `4` | 速效胰島素 | 注射標記、每小時加總、餐食歸屬 |
| `5` | 碳水化合物 | 目前不使用（飲食一律走 food.csv） |

> **type 1 不可混入 type 0。** 掃描值與歷史值在時間上重疊，兩者相加會重複計數，
> 涵蓋率會算出超過 100% 的假象，TIR 也會偏誤。轉檔時務必分開。

**血糖單位一律 mg/dL。** 若你的來源是 mmol/L，請先乘以 18.018 再轉出。

其餘欄位（長效胰島素、備註、血酮、試紙…）留空即可，本專案目前不使用。

## food.csv — 飲食紀錄

單純的表頭 + 資料，沒有抬頭列。

```
日期時間,餐別,品牌,產品名稱,攝取份量,熱量 (kcal),蛋白質 (g),脂肪 (g),碳水化合物 (g),備註
2026-03-02 08:10,早餐,示範,全麥吐司＋水煮蛋＋無糖豆漿,1份,380,18,12,45,
```

| 欄位名 | 說明 |
|---|---|
| `日期時間` | `YYYY-MM-DD HH:MM`（小時不補零也可以） |
| `餐別` | 早餐／午餐／晚餐／點心…任意字串。留空或「未指定」會讓位給同一餐次中有明確餐別的列 |
| `產品名稱` | 顯示在卡片與數值框上 |
| `碳水化合物 (g)`、`蛋白質 (g)`、`脂肪 (g)` | 數值；空白視為 0 |
| `熱量 (kcal)` | 用來判斷無熱量飲品 |
| `品牌`、`攝取份量`、`備註` | 選填，目前只有品牌與份量會被讀入 |

**一餐可以拆成多列**（主菜、白飯、飲料各一列）。**相隔 30 分鐘內的列會合併成
同一次進食**，營養素加總、品項以「＋」串接——不合併的話同一頓飯會拆成數張
餐後反應卡，共用同一劑胰島素、重複計算同一個血糖峰值。

合併後仍會依原始餐別分行顯示，例如晚餐 19:30 與點心 19:55 會呈現為：

```
晚餐　鮭魚＋糙米飯＋味噌湯
點心　黑巧克力
```

## 示範資料裡刻意鋪的情境

這 14 天不是隨機產生的，每個功能都有對應的樣本：

| 日期 | 情境 | 展示什麼 |
|---|---|---|
| 03-06 03:00 | 凌晨低血糖，持續 45 分鐘、最低 58 | 低血糖事件清單、P1 的事件計數 |
| 03-10 08:00–14:00 | 感測器斷線 6 小時 | 曲線不連線、涵蓋率降到 98%、每小時欄位留白 |
| 03-12 午後 | 血糖衝到 340 | `>250` 分區、每小時表的橘底格 |
| 03-14 19:30 / 19:55 | 晚餐與點心相隔 25 分鐘 | 餐次合併、分行標示餐別 |

產出的報告刻意落在「部分達標、部分未達標」：

```
TIR 62.0%   目標 >70   ✗        很高 3.3%    目標 <5    ✓
高+很高 37.7%  目標 <25  ✗        低+很低 0.3%  目標 <4    ✓
GMI 7.4%    目標 <7    ✗        CV 23.9%     目標 ≤36   ✓
```

全部達標的示範看不到「未達標」長什麼樣子，而那是報告視覺語言的一半。
